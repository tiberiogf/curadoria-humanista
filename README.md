# Curadoria Humanista (`@ahumanista`)

Página web inspirada no layout de perfil do Instagram de **Giovanna Biondi** ([@ahumanista](https://www.instagram.com/ahumanista/)), reunindo todas as 14 recomendações dos posts da série **Curadoria Anti-Alienação da Semana**:

1. **Edição de 22/10/2026** — *Curadoria Anti-Alienação para não ser um bocó* ([ver post original](https://www.instagram.com/ahumanista/p/DezvMohGtiX/)) • 8 recomendações
2. **Edição de 09/10/2026** — *Tudo que consumi nessa semana para não ser uma alienada* ([ver post original](https://www.instagram.com/ahumanista/p/DeUP8oSjsR4/)) • 6 recomendações

## Estrutura do Projeto

- `index.html` — Página principal com cabeçalho do perfil, feed interativo com os 2 posts do Instagram, modal de detalhes por publicação e listagem completa com filtros, thumbnails, comentários originais da Giovanna e links diretos para YouTube, Spotify, g1 e Amazon.
- `assets/` — Imagens locais (avatar do perfil, fotos de capa originais dos dois posts e thumbnails recortadas de cada slide).
