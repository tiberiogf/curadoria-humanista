# Curadoria Humanista (`@ahumanista`)

Página web inspirada no layout de perfil do Instagram de **Giovanna Biondi** ([@ahumanista](https://www.instagram.com/ahumanista/)), reunindo os materiais recomendados no post **Curadoria Anti-Alienação da Semana** ([ver post original](https://www.instagram.com/ahumanista/p/DezvMohGtiX/)).

## Estrutura do Projeto

- `index.html` — Página principal com cabeçalho do perfil, card interativo do post e lista de recomendações com comentários da Giovanna, thumbnails e links diretos para YouTube e Spotify.
- `assets/` — Imagens locais (avatar do perfil, foto de capa do post e thumbnails recortadas de cada slide como fallback offline).

## Como visualizar

Basta abrir o arquivo `index.html` em qualquer navegador moderno.
